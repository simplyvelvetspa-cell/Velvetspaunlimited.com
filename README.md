# Simply Velvet Spa

Interactive, mobile-first website for Simply Velvet Spa in Richmond, Virginia.

## Features

- Animated velvet-curtain welcome
- Celestial luxury visual direction
- Interactive experience finder
- Responsive, accessible layout
- Appointment request by email

The live site is deployed automatically through GitHub Pages whenever `main` is updated.

## Mobile app

The `mobile-app/` directory contains the native iOS and Android companion app. It shares the spa's room names, experience finder, Square booking flow, and purple-and-gold visual language while keeping app-store code separate from the public website.
